How to use it

  1. Upload this HTML file to a GitHub repository and enable GitHub Pages.
  2. Open the GitHub Pages HTTPS address on the Android phone and choose rover phone.
  3. Allow camera access. Send the displayed connection code to the viewer.
  4. Open the same HTTPS page on your computer, choose viewer, enter the code, and connect.
  5. Use Switch rover camera to switch between rear and front cameras.

Both devices need internet access. The rover phone's browser tab must remain open and awake. This page uses PeerJS's public signaling service and WebRTC; some restrictive networks may prevent a direct connection.
