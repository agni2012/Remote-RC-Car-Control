Connection notes

  • This version uses your own Node.js server for signaling.
  • Video uses WebRTC with a public STUN server. Some networks require a TURN server for connections across different networks.
  • For access outside your home Wi-Fi, expose this server over HTTPS/WSS (for example, with a domain and reverse proxy, or a secure tunnel).
  • Camera access requires HTTPS, except on localhost.

The server relays connection setup, not the video. The page does not record or store video.
